# MAKSON PROJECT

Браузерный рабочий стол с играми и утилитами. Эта копия предназначена для разработки в Codex Cloud или в обычном Linux-окружении. Все адреса приложений и API идут через один сервер Node.js.

| Команда | Что запускает |
| --- | --- |
| `npm start` | Рабочий стол, игры, общий буфер и Мемоинатор. Node.js 22+, пакеты npm для запуска не нужны. |
| `sh cloud/setup.sh` и `python3 cloud/run.py` | Также аккаунты и мессенджер «СВЯЗЬ». Нужен Python 3.12+. |
| `sh cloud/setup.sh --tools` и `python3 cloud/run.py --tools` | Также конвертер, загрузчик и экспорт Монтажки. Нужен Linux с доступными пользовательскими пространствами имён. |

По умолчанию сайт слушает порт `4173`. В облаке открой HTTP-превью этого порта. Для входа в «СВЯЗЬ» перед запуском задай `MAKSON_SITE_URL` равным точному публичному origin превью (схема и хост, без пути). Прокси превью должен сохранять исходный `Host`. Django слушает `127.0.0.1:3180`, обработчик файлов использует локальный Unix-сокет.

```sh
npm test
HOST=0.0.0.0 PORT=4173 npm start
```

Для полного запуска медиаобработки на Debian/Ubuntu установи `bubblewrap`, `ffmpeg`, `libreoffice`, `poppler-utils`, `pandoc`, `libcairo2` и `ca-certificates`. `cloud/run.py --tools` проверяет доступность изоляции до запуска. Если среда не разрешает запуск `bwrap`, пользуйся базовым режимом или перенеси обработчик в Linux-среду с поддержкой изоляции. Доступность скачивания конкретного видео зависит от источника и сети.

Облачная «СВЯЗЬ» пишет письма подтверждения в локальную `.cloud/mail/`. Тестовые письма, база, вложения и секрет Django создаются в `.cloud/`, СДВГПОЛИЯ использует `importopoly/.data/`, общий буфер — `.data/`. При сбросе облачной машины эти данные пропадут, если каталог не сохранён. Используй отдельные тестовые аккаунты. Настройка полноценной публичной почты, push и TURN находится за пределами локального превью.

Для разработки через чатбота см. [AGENTS.md](AGENTS.md) и [готовый промпт](CHATBOT.md).
